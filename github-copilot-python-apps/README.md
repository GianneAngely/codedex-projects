# Python Tkinter Mini Apps

Small desktop apps from the Codédex GitHub Copilot course.

- `rock_paper_scissors.py`: text version of Rock Paper Scissors against the computer
- `rock_paper_scissors_gui.py`: Tkinter version with emoji buttons, scoreboard (wins, losses, ties, rounds) and reset
- `calculator_gui.py`: Tkinter calculator with + − × ÷

**Stack:** Python 3, Tkinter (built in, no install needed)

## Run

```bash
python3 rock_paper_scissors_gui.py
python3 calculator_gui.py
```
